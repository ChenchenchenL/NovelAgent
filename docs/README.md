# NovelAgent 文档

NovelAgent 是面向个人作者的长期小说创作 Agent。文档以作者正文和创作工作区为中心，说明场景级增量写作、正典抽取、人物关系、剧情衔接、物品/身份/空间连续性、检索和恢复如何协作。

## 设计基准

1. 作者正文可以独立保存；抽取失败或模型低置信判断不能拦截作者写作。
2. Beat、段落和 Scene 是增量生成与采纳粒度，Chapter 是组织和发布聚合。
3. 正典主张必须保留来源、叙事时间、事实模态和作者确认状态。
4. 只有已确认结构才能进入确定性检查，LLM 抽取不能直接制造硬拦截。
5. 人物状态、关系事件和剧情事件必须能追溯到场景来源或作者声明。
6. 上游修改按细粒度影响图传播，不能默认使全书下游章节失效。
7. KG 和各种 RAG 都是可重建的检索能力；GraphRAG 是可选离线增强，不是普通续写依赖。
8. 唯一关键物品必须通过显式转移事件保持所有权守恒。
9. 影子身份在掉马前隔离真实身份，掉马后保留历史来源并按影响范围追踪。
10. 作者可以确认人物成长、跳切和剧情转折，系统不能静默替作者修正。

企业级多租户、计费、复杂分支合并和跨区域治理不属于当前个人创作闭环，除非后续需求明确提出，否则不作为架构主线。
